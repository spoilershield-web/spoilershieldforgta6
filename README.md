# 🛡️ Spoiler Shield for GTA 6 (Unofficial Fan Tool)

A lightweight, 100% local, zero-tracking Chrome extension that automatically blurs and mutes potential GTA 6 leaks, endings, and spoilers across YouTube, Shorts, X (Twitter), Reddit, and more.

🔗 **[Install from Chrome Web Store](https://chromewebstore.google.com/detail/ojiaoeefifmfhgefldkegfmohknjkjjh)**

## 🔒 Privacy & Security Architecture
- **100% Local Execution:** All keyword matching and DOM filtering happen strictly inside your browser.
- **Zero Data Collection:** No analytics, no external servers, no network requests.
- **DM & Password Blindness:** Explicitly excludes login pages, settings, and direct message routes (`/messages`, `/direct`, `/chat`, `/settings`, password/textarea inputs).

## ✨ Features
- **Targeted Protection:** Only blurs and mutes GTA 6 related spoilers/content without breaking your normal feed.
- **One-Click Reveal:** Unblur any card temporarily with a single click.
- **Custom Blocklist & Right-Click Hide:** Add custom blocked keywords or right-click any post to hide it immediately.
- **Bilingual UI:** Supports English (`EN`) and Turkish (`TR`).

## 🛠️ Manual Installation (Developer Mode)
1. Download or clone this repository.
2. Open `chrome://extensions/` in Chrome.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select this folder.
